# Lume Product Requirements Document (PRD)

**Objective**
Provide a high-speed personal health tracking Progressive Web App (PWA).

**Core Features**
1. **Health Connect Integration:** 10-minute heartbeat synchronization.
2. **AI Food Logging:** Leveraging Edge Functions for fast entry.
3. **Pill Tracker / Medication Alerts:** Persistent active notifications.

**Design Philosophy**
Must maintain a strictly minimalist UI focused on speed and data clarity.
